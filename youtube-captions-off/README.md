# YouTube Captions Off

iPhone の Safari で YouTube を見るとき、字幕を常にオフにし、動画広告を止めるユーザースクリプト。

- 動画を開いたとき、全画面にしたとき、次の動画に移ったときも字幕オフを保つ
- 動画広告は、そもそも入らないようにする。それでも流れた広告は、音を消して最後まで飛ばすか、スキップボタンを自動で押す
- 動画に重なるバナー広告と、ページ内の広告枠も隠す
- AdGuard などの広告ブロッカーは要らない。入れたままでも問題ない
- CC ボタンを押しても、何も表示されずにオフへ戻る。故障ではなく、常にオフにする仕様
- スクリプトは外部と通信しない。自動更新もしない
- 対象は m.youtube.com と www.youtube.com。ほかのサイトに埋め込まれた YouTube と YouTube Music は対象外

画面の表記は iOS のバージョンで変わる。この手順と表記が違うときは、近い名前の項目を選ぶ。

## インストール

所要時間は5分ほど。

### 1. Userscripts アプリを入れる

1. App Store で [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) をインストールする。無料
2. Userscripts アプリを開き、スクリプトの保存フォルダを選ぶボタンをタップする
3. 「このiPhone内」を開き、右上のフォルダのアイコンで `Userscripts` フォルダを作る。そのフォルダを選んで「開く」をタップする

### 2. Safari で Userscripts を有効にする

1. iPhone の「設定 > アプリ > Safari > 機能拡張 > Userscripts」を開く
2. 機能拡張を許可するスイッチをオンにする
3. 「その他の Web サイト」は「確認」のままにする。全サイトを許可する必要はない

### 3. スクリプトをインストールする

1. Safari で次の URL を開く。スクリプトの中身がテキストで表示される

   ```
   https://raw.githubusercontent.com/mizok-o/chrome-alltab-delete/main/youtube-captions-off/youtube-captions-off.user.js
   ```

2. Safari の機能拡張メニューから Userscripts を選ぶ
   - iOS 18 まで：アドレスバー左の「ぁあ」をタップする
   - iOS 26 以降：アドレスバーの「…」をタップし、機能拡張の項目から選ぶ
3. このサイトでの許可を求められたら「1日許可」を選ぶ。インストールにしか使わないので、常に許可しなくてよい
4. 「Userscript Detected」の表示で「Install」をタップする

### 4. YouTube で許可する

1. Safari で m.youtube.com を開く
2. 手順3と同じ機能拡張メニューから Userscripts を選ぶ
3. 許可を求められたら「常に許可」を選ぶ
4. 一覧に「YouTube Captions Off」が出て、スイッチがオンなら完了

### 5. 全画面用の補助設定

「設定 > アクセシビリティ > 字幕とキャプション」で「クローズドキャプション＋SDH」をオフにする。この設定は iPhone のすべてのアプリに効く。

## スクリプトのオン・オフ

1. Safari で m.youtube.com を開く
2. 機能拡張メニューから Userscripts を選ぶ
3. 一覧の「YouTube Captions Off」のスイッチで切り替え、ページを再読み込みする

字幕を見たいときは、この手順でオフにして再読み込みする。見終わったらオンに戻す。iPhone をほかの人が使うときも同じ。

## 実機での検証

先に、字幕が勝手に出る状態を作ってから試す。最初から字幕が出ない動画では、効いているのか分からない。

### 準備

1. スクリプトをオフにする。やり方は「スクリプトのオン・オフ」を参照
2. 字幕付きの動画を開く。ニュースや TED などの公式チャンネルなら大体ある
3. プレイヤーの CC ボタンをタップして字幕をオンにし、字幕が出ることを確かめる
4. 別の動画を開き、字幕が自動で出ることを確かめる。YouTube が字幕オンを覚えるので、これで準備完了

### 確認

スクリプトをオンに戻してページを再読み込みし、次の順に試す。

| # | 操作 | 合格の条件 |
|---|---|---|
| 1 | 字幕付きの動画を開いて再生する | 字幕が一瞬も出ない。CC ボタンがオフ表示になる |
| 2 | 全画面ボタンをタップする | 字幕が出ない。全画面プレイヤーの字幕メニューは「オフ」 |
| 3 | 全画面のまま30秒ほど再生し、全画面を閉じる | 字幕が出ないまま |
| 4 | 下のおすすめ動画をタップする | 字幕が出ない |
| 5 | 自動再生で次の動画に移るまで待つ | 字幕が出ない |
| 6 | 戻るボタンで前の動画に戻る | 字幕が出ない |
| 7 | CC ボタンで字幕をオンにしてみる | すぐオフに戻る |
| 8 | Shorts を開いてスワイプする | 字幕が出ない |
| 9 | Safari を完全に閉じて開き直し、動画を開く | 字幕が出ない |
| 10 | 広告が入りやすい動画を5本開いて再生する。音楽の公式 MV や人気チャンネルの新しい動画がよい | 5本とも広告が出ないか、出ても数秒以内に本編が始まる |
| 11 | 10を全画面でもう一度試す | 同じく広告が出ないか、数秒以内に本編が始まる |
| 12 | 広告が出た瞬間に音を聞く | 広告の音は鳴らない。本編に戻ると音が戻る |
| 13 | 再生速度を1.5倍にして見ている途中で広告が入る | 広告のあとも1.5倍のまま |
| 14 | 広告のない場面で、本編を1分ほど見る | 再生位置が勝手に飛ばない。速度も音も変わらない |

Safari を完全に閉じるには、画面の下端から上にスワイプして止め、Safari の画面を上に払う。

全項目が合格なら完了。2と3で字幕が出たら、補助設定の「クローズドキャプション＋SDH」がオフか確かめる。

### 不合格のときに記録すること

- 表の番号
- 広告の場合は、動画の前・途中・後のどこで出たか。広告の長さ、スキップボタンが出たか、音が鳴ったか
- iOS のバージョン。「設定 > 一般 > 情報」で分かる
- 動画の URL
- 可能なら画面収録

## うまくいかないとき

- Userscripts の一覧にスクリプトが出ない：インストールの手順4の許可を見直す
- 一覧に出るのに字幕が出る：「不合格のときに記録すること」をまとめて作者に送る

## 更新とアンインストール

- 更新：新しい版が出たら、インストールの手順3をやり直す。自動更新はしない
- アンインストール：Userscripts の一覧でスクリプトを左にスワイプして削除する。または「ファイル」アプリで保存フォルダから `youtube-captions-off.user.js` を消す
- スクリプトを使うと、YouTube 側の字幕設定もオフで記憶されることがある。アンインストール後に字幕を見たいときは CC ボタンでオンにする

## 開発者向け

### しくみ

- 主：video 要素の字幕トラックを `disabled` にする。オンに戻されたり新しいトラックが追加されたりしたら、すぐにオフをかけ直す
  - iPhone の Safari では、YouTube は字幕を video の字幕トラックとして渡し、トラックの状態を見てプレイヤーの字幕オン・オフを合わせている。トラックをオフにして変更を通知すると、プレイヤー自身も字幕オフの状態になる
  - 通知は、トラックの追加時と、video の読み込み・再生・全画面開始のたびに送る。プレイヤーが後から字幕オンを再適用しても揃え直せる
  - YouTube が自動でオンにする字幕は、追加された時点と default 属性を付け直された時点で自動選択の印を外す。字幕ファイルの読み込みも起きない
  - 対象は `subtitles` と `captions` の種類だけ。metadata などのトラックには触れない
- 補助：字幕の描画部分を CSS で隠す
- 動画広告その1（主）：YouTube のプレイヤーは、動画情報に入っている広告データ `adPlacements` などを見て広告を入れる。スクリプトはこのデータを取り除き、広告を予定させない
  - 取り除く対象は、ページの読み込み時に埋め込まれる動画情報と、次の動画へ移るときに取りに行く動画情報
  - 広告と本編が一体で配信される動画では取り除かない。取り除くと広告が本編扱いになり、その2で検知できなくなるため
  - ページ側で動いたときだけ効く。`@inject-into auto` で、Userscripts がページ側に入れなければ、その2だけで止める
- 動画広告その2：それでも広告が流れたら、プレイヤーに付く `ad-showing` で検知する。音を消し、スキップボタンを押し、広告の最後まで飛ぶ
  - 飛べるところまで読み込めていなければ、16倍速で早送りする。飛べないのに飛ぼうとすると再生が止まり続けるため
  - 本編の再生速度と音の状態を覚えておき、広告のあとに戻す
  - 3分を超える長さの動画では飛ばず、広告の間だけ早送りする。広告と本編が一体で配信されている場合に、本編まで飛ばさないため
- バナー広告とページ内の広告枠は CSS で隠す
- SPA 遷移で video が差し替わっても、DOM 監視と video のイベントで拾い直す
- YouTube の部品名が変わったら、スクリプト冒頭の `CONFIG` だけ直せばよい

### 既知の限界

- www.youtube.com と iPad の Safari は、字幕トラックを使わず字幕を自前で描く。ここでは CSS で隠すだけになり、CC ボタンはオン表示のまま残ることがある
- shadow DOM の中の video や、DOM に入る前の video は監視しない。現在の YouTube ではどちらも使われていない
- 広告と本編が一体で配信される場合は、その2の早送りとスキップボタンに頼る。iPhone の Safari が16倍速に対応していなければ、広告は音なしで流れる
- Userscripts がページ側に入れない場合は、その1が効かない。どちら側で動いたかは、Web インスペクタで html 要素の `data-yt-captions-off` 属性を見れば分かる。`page` ならその1も効いている
- ページ内の広告枠の部品名は、実機では確かめていない
- テストは Chromium で動かしている。default 字幕の自動選択の順序など WebKit 固有の動きは、実機での検証で確かめる

### テスト

YouTube の字幕処理と広告処理を再現した模擬プレイヤーで、要件を自動で確かめる。

```sh
cd youtube-captions-off
npm ci
npx playwright install chromium
npm test
```

確かめていること：

- 対照：スクリプトなしでは字幕が出る。テストが字幕を検出できることの確認
- 動画を開いても字幕が一瞬も showing にならず、字幕ファイルも読み込まれない。プレイヤーも字幕オフになる
- 字幕以外のトラックには触れない
- 全画面の標準プレイヤー側で字幕をオンにされてもオフに戻る
- 次の動画・おすすめへ移っても字幕が出ない
- 何度オンにされても戻し、無限ループにならない
- プレイヤーが監視を遅れて始め、後から字幕オンを再適用してもオフに揃う
- 字幕の描画部分は CSS で隠れる
- 対照：スクリプトなしでは動画情報に広告データがあり、広告が最後まで流れる
- 読み込み時・次の動画・入れ子の動画情報から広告データが消え、動画の情報は残る。本編と一体で配信される動画では消さない
- 広告を最後まで飛ばし、再生速度と音を元に戻す。広告の再生中は音を消す
- 飛ばせない広告は早送りで終わらせ、再生が止まり続けない
- スキップボタンがあれば押す。バナー広告は隠れる
- 本編と一体の長い動画は飛ばさず、広告の間だけ早送りする
- 広告でない本編は飛ばさず、速度も音も変えない
- 広告のあとも字幕はオフのまま
- 外部と通信しない。自動更新しない。読み込みの早い段階で動く。YouTube の部品名は1か所だけ

### 実機で詳しく調べる

Mac の Safari の Web インスペクタで、iPhone のページを調べられる。

1. iPhone の「設定 > アプリ > Safari > 詳細 > Webインスペクタ」をオンにする
2. ケーブルでつないだ Mac の Safari で、「開発」メニューから iPhone のページを選ぶ
3. コンソールで `[...document.querySelector('video').textTracks].map(t => t.kind + ':' + t.mode)` を実行する。subtitles と captions がすべて `disabled` なら字幕トラックはオフ
4. 字幕が出ているのにトラックがオフなら、字幕部分の class 名を調べて `CONFIG.captionSelectors` に足す
