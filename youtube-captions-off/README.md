# YouTube Captions Off

iPhone の Safari で YouTube を見るとき、字幕を常にオフにするユーザースクリプト。

- 動画を開いたとき、全画面にしたとき、次の動画に移ったときも字幕オフを維持する
- 手動でオンにする仕組みはない
- 外部と通信しない

## インストール

所要時間は5分ほど。

### 1. Userscripts アプリを入れる

1. App Store で [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) をインストールする。無料
2. Userscripts アプリを開き、スクリプトの保存フォルダを設定する
   - 「Set Userscripts Directory」をタップし、「このiPhone内」に `Userscripts` フォルダを作って選ぶ。iCloud Drive でもよい

### 2. Safari で Userscripts を有効にする

1. iPhone の「設定 > アプリ > Safari > 機能拡張 > Userscripts」を開く
2. 「機能拡張を許可」をオンにする
3. 「その他の Web サイト」を「許可」にする。気になるなら youtube.com と raw.githubusercontent.com だけ許可する

### 3. スクリプトをインストールする

1. Safari で次の URL を開く。スクリプトの中身がテキストで表示される

   ```
   https://raw.githubusercontent.com/mizok-o/chrome-alltab-delete/main/youtube-captions-off/youtube-captions-off.user.js
   ```

2. アドレスバーの「ぁあ」かページメニューのボタンをタップし、Userscripts を選ぶ
3. 「Userscript Detected」の表示で「Install」をタップする
4. 一覧に「YouTube Captions Off」が出て、スイッチがオンになっていれば完了

うまく出ない場合は、上の URL のテキストを `youtube-captions-off.user.js` という名前でファイルに保存し、手順1で選んだフォルダに入れる。

### 4. 補助の設定

- 全画面時の補助：「設定 > アクセシビリティ > 字幕とキャプション」で「クローズドキャプション＋SDH」をオフにする
- 広告ブロック。任意：App Store で AdGuard を入れ、「設定 > アプリ > Safari > 機能拡張」で AdGuard のコンテンツブロッカーをすべてオンにする

## 実機での検証

ポイントは、先に「字幕が勝手に出る状態」を作ってから、スクリプトで消えるかを見ること。最初から字幕が出ない動画では、効いているのか分からない。

### 準備：字幕が出る状態を作る

1. Userscripts の一覧で「YouTube Captions Off」のスイッチをオフにする
2. Safari で m.youtube.com を開き、字幕付きの動画を開く。ニュースや TED などの公式チャンネルなら大体ある
3. プレイヤーの字幕ボタン CC をタップしてオンにし、字幕が出ることを確かめる
4. 別の動画を開き、字幕が自動で出ることを確かめる。YouTube が字幕オンを記憶するので、これで「勝手に出る状態」になる

### 確認：スクリプトをオンにして試す

Userscripts でスイッチをオンに戻し、ページを再読み込みしてから、次の順に試す。

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 字幕付きの動画を開いて再生する | 字幕が一瞬も出ない。CC ボタンがオフ表示になる |
| 2 | 全画面ボタンをタップする | 字幕が出ない。標準プレイヤーの吹き出しメニューは「オフ」 |
| 3 | 全画面のまま30秒ほど再生し、全画面を閉じる | 字幕が出ないまま |
| 4 | 下のおすすめ動画をタップする | 字幕が出ない |
| 5 | 自動再生で次の動画に移るまで待つ | 字幕が出ない |
| 6 | 戻るボタンで前の動画に戻る | 字幕が出ない |
| 7 | CC ボタンや全画面の吹き出しメニューで字幕をオンにしてみる | すぐオフに戻る。常にオフにする仕様 |
| 8 | Safari を一度閉じて開き直し、動画を開く | 字幕が出ない |

すべて期待どおりなら合格。2と3で字幕が出た場合は、補助の設定のアクセシビリティ設定がオフになっているか確かめる。それでも出るなら、どの手順で出たかを記録する。

### 片付け

準備で字幕オンを記憶させたままでも、スクリプトがあれば字幕は出ない。気になるならスクリプトをオフにして CC ボタンで字幕をオフにしておく。

### うまくいかないとき

- Userscripts のアイコンを開き、YouTube のページでスクリプトが動いているか確かめる。出ていなければ手順2の許可設定を見直す
- 詳しく調べる場合は、Mac の Safari の Web インスペクタで iPhone のページをのぞける。iPhone の「設定 > アプリ > Safari > 詳細 > Webインスペクタ」をオンにし、ケーブルでつないだ Mac の Safari で「開発」メニューから選ぶ
  - コンソールで `[...document.querySelector('video').textTracks].map(t => t.mode)` を実行し、すべて `disabled` なら字幕トラックはオフ
  - 字幕が画面に出ているのにトラックがオフなら、字幕部分の class 名を調べてスクリプト冒頭の `CONFIG.captionSelectors` に足す

## しくみ

- 主：video 要素の字幕トラックを `disabled` にする。オンに戻されたり新しいトラックが追加されたりしたら、すぐにオフをかけ直す
  - iPhone の Safari では、YouTube は字幕を video の字幕トラックとして渡し、トラックの状態を見てプレイヤーの字幕オン・オフを合わせている。トラックをオフにして変更を通知すると、プレイヤー自身も字幕オフの状態になる
  - YouTube が自動でオンにする字幕は、追加された時点で自動選択の印を外す。字幕ファイルの読み込みも起きない
- 補助：字幕の描画部分を CSS で隠す
- SPA 遷移で video が差し替わっても、DOM 監視と video のイベントで拾い直す
- YouTube の部品名が変わったら、スクリプト冒頭の `CONFIG` だけ直せばよい

## テスト

YouTube の字幕処理を再現した模擬プレイヤーで、要件を自動で確かめる。

```sh
cd youtube-captions-off
npm install
npx playwright install chromium
npm test
```

確かめていること：

- 対照：スクリプトなしでは字幕が出る。テストが字幕を検出できることの確認
- 動画を開いても字幕が出ず、プレイヤーも字幕オフになる。字幕ファイルも読み込まれない
- 全画面の標準プレイヤー側で字幕をオンにされてもオフに戻る
- 次の動画・おすすめへ移っても字幕が出ない
- 何度オンにされても戻し、無限ループにならない
- 字幕の描画部分は CSS で隠れる
- 外部と通信しない。読み込みの早い段階で動く。YouTube の部品名は1か所だけ

iOS の全画面プレイヤーそのものは再現できないので、実機での検証は別に要る。
